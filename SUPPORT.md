## Before Opening an Issue / 开 Issue 前

1. Check the [README](README.md) and [docs/architecture.md](docs/architecture.md) first / 先查文档
2. Search existing issues for duplicates / 搜索是否已有重复 issue
3. Include in your report / 报告中包含：
   - OS + bash version (`bash --version`) / 操作系统与 bash 版本
   - The exact command you ran / 你运行的确切命令
   - Full output (or the relevant portion) / 完整输出（或相关片段）
